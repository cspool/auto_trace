# A033：FX Rule Reconstruction Gap Skill

## Objective

执行一个强制的 `workflow_gap_skill_generation` Goal，生成：

```text
workload_profile/skills/qwen-dcu-fx-process-reconstruction/
```

该 Skill 位于 FX trace 与手工 process visualization 之间，只负责从已验证
的 fixed-input FX DAG artifact 生成 rule-derived process reconstruction
证据并校验完整性。

## 唯一权威

能力规范只来自：

- `workload_profile/workflows/03_2_04_2_fx_branch.md`
  - 引言中 reconstruction 位于两个参考 Skill 之间的边界；
  - `Ref` 中 reconstruction script 的职责边界；
  - `## 2. Rule Reconstruction` 全部内容。

当前项目具体绑定只能来自 manifest 固定的 binding evidence：

- `pra2026-bh408/vllm/model_executor/models/qwen3_5.py`
- `workload_profile/fx/tools/reconstruct_r042_fx_process.py`
- `workload_profile/fx/tools/validate_r042_fx_process.py`

已有 `R042` 命名只证明当前实现与 schema。目标 Skill 不得把旧 runtime
Goal ID、固定事件数、固定 run ID 或历史 artifact 写成通用条件；运行时应
从 A032/R032 handoff 推导本次输入、顺序和分母。

## 必须生成

目标文件集合严格为：

```text
SKILL.md
agents/openai.yaml
```

Skill 必须完整编码：

1. 只消费已完成且重新验证通过的 FX trace handoff；
2. 校验 trace root、source trace、canonical manifest、contract、hash、
   ordered event ids 和 single-call `layer_occurrence` gate；
3. 拒绝参考只读树、复用目录和任何已存在 reconstruction manifest；
4. 对全部 ordered FX event 递归执行 rule reconstruction；
5. 为每个事件生成且只生成 process JSON、Markdown 和 node CSV，并生成
   root-level JSON/CSV manifests；
6. 逐事件检查 status、order、uniqueness、processed count 和所有声明产物；
7. 每个 FX node 必须恰好落入一个 dependency-ordered process range；
8. process label 是规则派生标签，不是 FX metadata、模块所有权或 custom-op
   内部证据；
9. reconstruction 只生成 ops/tables/ranges/shape/dtype 证据，不生成中文
   解释或手工字符图；
10. 任一错误、缺失、重复、hash 漂移或覆盖不完整都必须停止后继 visualization。

## 边界

- A032/R032 拥有 eager sampling、offline specialization 和 FX capture；
- A042/R042 拥有逐 process 中文解释和手工 tensor-axis visualization；
- A052/R052 拥有分支最终 event-set coverage 和 completion record；
- 本 Skill 不修改 `fx_graph*`，不执行 GraphModule，不推断 opaque
  vLLM/ROCm/DCU custom op 内部；
- 不把 binding-evidence 业务脚本复制进 Skill。

## 未决绑定

运行时必须确认或适配：

- 去除旧 `R042` 命名后的稳定 reconstruction 命令/参数；
- 新 R033 runtime handoff 的实际路径和 schema；
- 当实际 FX artifact schema 漂移时的当前项目规则绑定。

未确认不允许省略重建，只允许阻塞或从当前源码/实际 artifact 发现。

## Handoff

完成后写：

```text
workload_profile/workflows/project_adaptation/artifacts/A033/handoff.json
```

它必须是最小 Workflow-gap handoff，只索引目标 Skill 并声明固定 authority。

## 禁止事项与完成条件

不得执行 FX、模型、GPU 或 reconstruction；不得修改现有 target Skills、
Workflow、binding evidence、manifest、runner、verifier 或 canonical state。

只有两个目标文件完整覆盖 authority、具体绑定均有证据或明确 runtime
discovery、边界清楚、最小 handoff 写完且外部 gate 可通过时，才可标记
`complete`。
