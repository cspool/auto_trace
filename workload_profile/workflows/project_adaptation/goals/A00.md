# A00：共享 Run Contract 与 Event Conservation Gap Skill

## Objective

执行一个强制的 `workflow_gap_skill_generation` Goal，生成：

```text
workload_profile/skills/qwen-dcu-workload-profile-contract-audit/
```

该 Skill 负责运行时建立或审计两条 workload-profile 分支共用的 run mode、
canonical run contract、event key、evidence boundary 和 event-set
conservation。它不运行 profiler、Algorithmic Trace、Dispatch 或 FX。

## 唯一权威

能力规范只来自：

- `workload_profile/workflows/00_overview.md`
  - `Run Modes`
  - `Canonical Run Contract`
  - `Canonical Event Keys`
  - `Event Families And Conservation`
  - `Evidence Boundaries`
  - `Shared Completion Checks`

当前项目具体绑定只能来自 manifest 固定的 binding evidence：

- `workload_profile/algorithmic_trace/tools/finalize_r02.py`
- `workload_profile/fx/tools/finalize_r032.py`
- `workload_profile/fx/tools/finalize_r042.py`

这些已有工具只证明当前项目的 contract、hash、ordered-event 和 handoff
schema；其中出现的既有运行 ID、事件数和 artifact 只能作为绑定事实，不能
冒充下一次运行证据。

## 必须生成

目标文件集合严格为：

```text
SKILL.md
agents/openai.yaml
```

Skill 必须完整表达：

1. `REFERENCE_AUDIT` 与 `FRESH_RUN` 二选一，以及只读/唯一输出目录规则；
2. canonical run contract 的必需字段、可比性和有意差异记录；
3. forward/layer/decision/transition key 及 `layer_occurrence` 约束；
4. `F/L/S/R/T/D/X` 的集合定义、key-set conservation 和禁止只比 row count；
5. profiler、Algorithmic Trace、Dispatch 和 FX 的证据边界；
6. hash、order、uniqueness、source-path、contract-id 与 handoff 一致性校验；
7. 未显式捕获 transition 时必须记录 missing，不能把 q-length 变化冒充
   decision-to-application causal join；
8. 失败、停止和 shared completion 条件。

## 边界

- 不重复 A01 的 patch-target 方法；
- 不重复 A02 的 trace/selection 方法；
- 不执行 A031/A041/A032/A033/A042 的业务能力；
- 不承担 Dispatch/FX 分支特有的最终报告；
- 不把当前 runtime artifact 复制进 Skill；
- 不发明并发/分布式覆盖；未确认的 worker/rank 绑定必须运行时发现。

## Handoff

完成后写：

```text
workload_profile/workflows/project_adaptation/artifacts/A00/handoff.json
```

它必须是最小 Workflow-gap handoff，`outputs.skill` 只能指向目标 Skill，
并声明 manifest 固定的 Workflow authority。

## 禁止事项与完成条件

不得执行 Workflow、模型、GPU 或业务脚本，不得修改参考 Workflow、相邻
Skill、manifest、runner、verifier 或 canonical state。

只有两个目标文件完整、authority/evidence/未决绑定均可追溯，最小 handoff
写完且外部 gate 可通过时，才可标记 `complete`。
