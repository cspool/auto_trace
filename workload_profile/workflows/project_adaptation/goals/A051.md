# A051：Dispatch 手工可视化与分支覆盖审计 Gap Skill

## Objective

执行一个强制的 `workflow_gap_skill_generation` Goal，生成：

```text
workload_profile/skills/qwen-dcu-dispatch-visualization-coverage-audit/
```

该 Skill 只补全 Dispatch 参考 Skill 未覆盖的逐事件手工 character
visualization，以及把 canonical target、profile、reconstruction、review、
audit 和人工可视化连接成分支完成证据。

## 唯一权威

能力规范只来自：

- `workload_profile/workflows/03_1_04_1_dispatch_branch.md`
  - `## Manual Character Visualization`
  - `## Strict Review And Audit` 中跨事件集合相等、人工 visualization
    覆盖和分支完成要求
  - `## Manual Completion Record`

当前项目尚无经过独立确认的 `workload_profile/dispatch` 实现文件，因此
manifest 的 binding-evidence 集为空。空 evidence 不允许删除能力；所有
具体 Qwen/DCU dispatch 路径、schema、review/audit 工具和 visualization
artifact 绑定必须保留为 runtime discovery。

## 必须生成

目标文件集合严格为：

```text
SKILL.md
agents/openai.yaml
```

Skill 必须完整编码：

1. 只消费 A041/R041 已验证的 per-event reconstruction/ONNX evidence 和
   Unit-2 canonical ordered event set；
2. 每个事件必须单独生成 `dispatch_process_visualization.md`；
3. 手工字符图必须展示 original/small shapes、tensor-id producer-consumer
   边界、相关 op indices/modules、in-place/alias 变化和证据支持的 cache、
   rectangular attention、visual-adjust 或 similarity 分支；
4. 禁止用 stage 名单、共享模板副本或自动 bulk renderer 代替逐事件分析；
5. 最终检查 canonical target、profile、pipeline manifest、review match、
   audit pass 和 visualization event sets 完全相等；
6. 检查每个事件的 tensor-id edge 可重算、op/module coverage、可选 stage、
   rectangular shape、ONNX checker 和 code-page 一一对应；
7. 记录选择 handoff hash、contract、event-set digest、动态 N、profile/
   reconstruction root、review/audit/visualization 数和 reviewer/time；
8. 任一 blocker、missing artifact、`needs_revision`、audit issue 或未人工
   review 的 visualization 都必须保持 incomplete。

## 边界

- A031/R031 拥有 filtered Dispatch capture 和 profile validation；
- A041/R041 拥有 dispatch reconstruction、tensor dependency、small-shape
  Torch、ONNX、per-layer review 和 strict reconstruction audit；
- 本 Skill 不重新选择事件、不修复 capture/reconstruction、不生成 ONNX；
- 历史 reference tree 只可读审计，不能冒充 fresh completion。

## 未决绑定

必须在运行时从实际 A031/A041 handoff 与当前项目文件发现：

- Qwen/DCU Dispatch profile/reconstruction roots；
- full-schema op、tensor-id 和 alias 字段；
- review/audit 命令；
- visualization companion 与 completion-record 的当前路径/schema。

## Handoff

完成后写：

```text
workload_profile/workflows/project_adaptation/artifacts/A051/handoff.json
```

它必须是最小 Workflow-gap handoff，只索引目标 Skill 并声明固定 authority。

## 禁止事项与完成条件

不得执行模型、Dispatch、reconstruction、ONNX、visualization 或 audit；
不得修改 Workflow、相邻 Skill、manifest、runner、verifier 或 canonical
state。

只有两个目标文件完整、全部无证据绑定显式 runtime-deferred、能力边界清楚、
最小 handoff 写完且外部 gate 可通过时，才可标记 `complete`。
