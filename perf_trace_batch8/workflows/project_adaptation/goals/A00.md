# A00: Common Adapt Goal Contract

## Purpose

Apply this contract to every serial Adapt Goal in this product.

## Migration-only boundary

- Read the pinned workflow and reference Skill files as source text.
- Migrate project, model, runtime, accelerator, path, command, artifact, and
  evidence bindings into the declared project Skill.
- Package workflow constraints not covered by a reference Skill without
  weakening the reference method, validation, stop, or evidence semantics.
- Treat the hash-pinned trace profile as the authoritative execution target.
  Serial Adapt Goals and serial runtime Goals do not imply a single accelerator:
  every generated project Skill must preserve the profile's complete topology.
- Do not run inference, GPU/DCU work, profilers, trace collection, PMC replay,
  report generation, or a generated project Skill.
- The final runtime-scheduler Goal may run only the generated scheduler's
  no-execution `--dry-run`.

## Serial contract

- Consume the immediately preceding Adapt handoff and cumulative immutable
  ledger before editing.
- Modify only the declared output paths and scheduler-assigned Adapt
  artifact/handoff outputs.
- Validate source hashes and the declared project-Skill or scheduler bundle.
- Commit a complete handoff before the scheduler advances to the next Goal.
- Keep `workflow_execution_performed=false` and
  `project_skill_execution_performed=false` in every Adapt handoff.
